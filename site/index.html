Close the loop on every comment.

Readers tick a box and get an email when someone replies to them or comments on the post. Double opt-in, one-click unsubscribe, and nothing a stranger can abuse.

Made to be safe first

A public form that sends email must never be a way to flood a stranger's inbox. Guests confirm first, links are signed, and only approved comments are ever sent.

For developers

A REST API, WP-CLI commands, Abilities API registrations, overridable email templates, and actions and filters for everything that happens.

Change who gets what

add_filter('ruvelo_comment_subscriptions_should_notify',
    function (bool $send, WP_Comment $comment) {
        return $send && $comment->comment_type === 'comment';
    }, 10, 2);

From the command line

wp ruvelo-comment-subscriptions import stcr --dry-run
wp ruvelo-comment-subscriptions list --post=42
wp ruvelo-comment-subscriptions queue run
